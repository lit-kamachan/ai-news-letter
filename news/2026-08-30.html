01｜モデル・リリース速報フロンティアモデルの新版・新機能

Anthropic、ラボ機器操作の標準規格「MHS」を研究プレビュー公開EN
Anthropicは2026年8月27日、AIエージェントが顕微鏡・液体分注装置・ロボットアームなどの実験・製造機器を標準化されたコマンドで直接操作できる「Model Hardware Standard（MHS）」の研究プレビューを、HHMI Janelia Research Campusと共同で公開した。従来は数週間〜数カ月かかっていた機器の統合作業を数時間〜数分に短縮できるとしている。
なぜ重要か：モデル非依存の設計で、Anthropic以外のモデルでも利用可能。将来的にオープンソース化する方針で、AIエージェントの操作範囲が「画面の中」から「物理的な機器」へ広がる標準化の第一歩となる。

なぜ重要か：社内ダッシュボードやレガシーシステムなど、API連携のない業務ツールにもClaudeが直接アクセスできるようになる。金融・法務・医療など機密性の高い業務での利用は引き続き非推奨としており、自律化と安全対策を同時に進める姿勢がうかがえる。

04｜新しい使い方の発見プロンプト術・ワークフロー・「その手があったか」系

Claude Code、--restrictedモードでエージェントの実行権限を絞れるようにEN
Anthropicは2026年8月27日、Claude Code v2.1.248をリリースし、`--restricted`フラグ（環境変数`CLAUDE_CODE_RESTRICTED=1`でも可）を追加した。コマンド実行・コード実行ツールとWebFetchを取り除き、ファイル操作を作業ディレクトリ内に限定、`bypassPermissions`も拒否する。ユーザー・プロジェクト・ローカルの設定ファイルも読み込まない。
なぜ重要か：信頼できないリポジトリや共有端末でのレビュー作業など「触らせたいが暴走はさせたくない」場面向けの安全モードを明文化したもので、権限設計の粒度がさらに細かくなっている。

Claude Code、サブエージェントの動きをRemote Controlでライブ監視できるようにEN
Claude Code v2.1.251（2026年8月28日リリース）は、フォアグラウンドで動くサブエージェントのツール呼び出しと結果をRemote Controlクライアントにリアルタイムでストリーミング表示する機能を追加した。あわせてモデル切り替えを制御できる`PreModelSwitch`／`PostModelSwitch`フックも追加された。
なぜ重要か：複数のサブエージェントを並行稼働させる運用が広がる中、「今どのエージェントが何をしているか」を外から覗ける可視性が実運用のボトルネックになっていたことを示しており、マルチエージェント運用の観察性が一段上がった。

Claude Codeの--restrictedモードを試してみる

手順：①ターミナルで `claude --restricted`（または環境変数 `CLAUDE_CODE_RESTRICTED=1` を設定）で起動する → ②コマンド実行・コード実行系ツールとWebFetchが自動的に外れ、ファイル操作が作業ディレクトリ内に制限されていることを確認する → ③グローバル・プロジェクトの設定ファイルを読み込まない状態になるので、信頼できないリポジトリのレビューや共有端末での一時利用など「触らせたいが暴走はさせたくない」場面で使ってみる。bypassPermissionsも拒否されるため、危険な自動実行を防ぎながら安全にコードを覗ける。
収集条件／直近24〜72hを中心に、海外・日本のソースを半々。出力は日本語（英語ソースは翻訳・要約）。出典リンクを付けられない項目は載せていない。
