01｜モデル・リリース速報フロンティアモデルの新版・新機能

Claude Code v2.1.259、組織全体へのMCP配布と無人実行向け設定を追加EN
managedMcpServers設定で組織のHTTP/SSE型MCPサーバーを全ユーザーへ一括配布できるようになった。無人稼働のヘッドレスホスト向けに--permission-prompts noneを追加し、GitLabのglab mrコマンドをマージリクエストとして認識、claude plugin validateに機械可読な--jsonオプションを追加。あわせて、複数セッションを同時に開くと互いの~/.claude.json変更を無言で上書きしていたバグを修正した。
なぜ重要か：個人の使い勝手ではなく、組織として何を配布し・誰に何を許可するかを管理者側で制御する機能が優先的に積み上がっている。
GitHub anthropics/claude-code·2026/9/2·原文
Claude Code v2.1.260、Fable 5.1のキャッシュ漏れバグを修正EN
Fable 5.1でツール呼び出し後に追加されるコンテキストがプロンプトキャッシュに乗らず、毎回非キャッシュ扱いで送信し直されていたバグを修正。会話中に/effortを変更してもキャッシュが無効化されなくなった。会話横にdiffパネルを追加し、/costとステータスラインにキャッシュミスの推定理由（ツール定義やシステムプロンプトの変更、TTL切れなど）を表示するようになった。
なぜ重要か：修正前は同じ処理でも最大40倍のコスト差が生じ得た。キャッシュ挙動を可視化したことで、コスト増の原因を利用者自身が突き止められるようになった。
GitHub anthropics/claude-code·2026/9/3·原文
Claude Code v2.1.261、未使用スキルの棚卸し機能「/skill-doctor」を追加EN
読み込み済みだが使われていないスキルとそのコンテキスト消費量を一覧表示する/skill-doctorを追加。組織ポリシーが読み込めない理由（プロキシがエンドポイントを通していない等）を/statusとclaude doctorに表示するようになり、bashOutputMaxChars/taskOutputMaxCharsでコマンドやバックグラウンドタスクの出力をファイル退避せず受け取れる上限を最大128Kまで拡大した。
なぜ重要か：スキルを増やすほどコンテキストを消費する構造に対し、削るべき候補を機械的に提示できるようになった。組織ポリシーの障害原因も、人が推測していた部分を診断機能に肩代わりさせる方向。
GitHub anthropics/claude-code·2026/9/4·原文

02｜Cowork中心の活用事例エージェント・社内導入のリアルな使い方

エクスペリサス、Claude Codeを全社導入し業務スキル743件を社内共有JP
社員・業務委託の計59名を対象に2026年7月〜8月に全社研修を実施。8月末時点で45名が743件のスキル（AIが読んで実行できる手順書）と127体の業務別AIエージェントを社内共有基盤に登録した。研修後の社内アンケートでは非エンジニア職の53%が日常的にClaude Codeを活用し、そのうち69%が「同じ成果物にかかる時間が半分以下になった」と回答した。
なぜ重要か：手順書を人が読んで再現するのではなく、他の社員のAIがその手順をそのまま実行できる形で蓄積する仕組みが、非エンジニア中心・59名規模の企業でも実際に回り始めている。
PR TIMES（エクスペリサス）·2026/9/3·原文
PwC、Claude Code/Coworkの本番運用で保険引受を10週間から10日間に短縮EN
PwCは保険引受・サイバーセキュリティ・HR変革・メインフレーム刷新などの実業務にClaude CodeとCoworkを組み込んで運用している。AnthropicのCEOダリオ・アモデイ氏は「10週間かかっていた保険引受が10日間になった」事例を挙げ、案件によっては納期を最大70%圧縮しているとした。
なぜ重要か：パイロットではなく本番の業務プロセスに組み込まれた結果として、リードタイムが桁で変わる事例が具体的な数字とともに示された。
