01｜モデル・リリース速報フロンティアモデルの新版・新機能

Sakana AI、単体モデルに頼らない「Fugu Max」「Fugu Ultra v2」EN
東京のSakana AIが9月11日、オーケストレーション型モデル「Fugu Max」と「Fugu Ultra v2」を発表。既存モデル群にタスクを振り分け、自身を再帰的に呼び出す設計で、自社の独自フロンティアモデルには依存しない。Fugu Ultra v2は入力$5・出力$30（100万トークンあたり）、コンテキスト窓100万トークンで、複雑な多段階推論・自律調査・フルスタック開発に照準を合わせる。
なぜ重要か：自前でフロンティアモデルを持たず複数モデルを束ねる「ルーター型」の設計が、単体モデルの性能競争とは別の軸として台頭してきた。
Sakana AI公式ブログ·2026/9/11·原文
Claude Code v2.1.268、サードパーティ互換エンドポイントの400エラーを修正EN
Anthropicは9月10日、Claude Codeのv2.1.268をリリース。サードパーティのAnthropic互換エンドポイント（ANTHROPIC_BASE_URL）でv2.1.265以降発生していたHTTP 400エラーを修正し、WebFetchが応答を返さないサーバーで無期限にハングする不具合には300秒のタイムアウトを追加。長時間アイドル状態でのCPU高負荷なども合わせて修正した。
なぜ重要か：地味な安定性修正の積み重ねが、企業が自社ゲートウェイ経由でClaude Codeを本番運用する上での信頼性を左右する。
GitHub anthropics/claude-code·2026/9/10·原文
Google、Gemini Windows版デスクトップアプリを提供開始EN
Googleは9月10日、Windows 10/11向けのGemini専用デスクトップアプリを正式リリース。Alt+Spaceのショートカットで即座に呼び出せ、Gmail・Google Driveと連携して文書要約や長期プロジェクトの支援ができる。動作要件はRAM 8GB・空き容量200MB以上で、4月提供済みのMac版に続く展開。
なぜ重要か：OS常駐のショートカット起動という導線を各社が競って押さえに行っており、モデル性能だけでなく「どこから呼び出せるか」が使われ方を左右する段階に入った。
TechBriefly·2026/9/11·原文
このカテゴリの流れ：モデル単体の性能誇示より、複数モデルの束ね方（Sakana）とOS常駐という導線（Gemini for Windows）、地味な安定性修正（Claude Code）など、使われる場所と仕組みの整備が主戦場になっている。

02｜Cowork中心の活用事例エージェント・社内導入のリアルな使い方

HubSpot、Cowork活用事例を公開EN
AnthropicはHubSpotのプロダクト・マーケティング部門のリーダー9人への取材をもとにケーススタディを公開。各チームはCoworkに定型業務を任せ、人が離席中でもタスクをスケジュール実行させることで、マーケター本来の業務に時間を充てられるようになったと説明している。
なぜ重要か：「エージェントに何を渡すか」の判断がチームごとに分散して進んでおり、全社一括導入より現場主導の使い分けが実態として先行している。
Claude by Anthropic（Customer Stories）·2026年9月·原文
Shopify、コーディングエージェントで6人・12週間のネイティブアプリ全面再構築EN
Shopifyは9月10日、React Nativeで統一していたモバイルアプリをSwift・Kotlinの別コードベースに戻す方針転換を明らかにした。エンジニア6人のチームが構想からストア公開までを12週間で完了。コーディングエージェントが実装・翻訳・テスト・レビューの作業量をこなせるようになったことで、1つの共有コードベースより2つのネイティブコードベースを保守する方が安上がりという判断に至った。
なぜ重要か：「エージェントがあるから複数コードベースの重複コストが下がる」という、クロスプラットフォーム前提を覆す設計判断が実例として出てきた。

Anthropic、Enterprise向け「Smart Reports」をベータ提供EN
Anthropicは9月上旬、Claude Enterpriseプラン向けに「Smart Reports」をベータ公開。チームがClaudeをどう使い、どんな成果物ができ、コストはいくらか、どこでつまずいているか、どのパターンを共有スキルとして切り出す価値があるかを分析してレポートする機能。
なぜ重要か：導入後の焦点が「使わせること」から「使われ方を可視化し、再利用可能な形に落とし込むこと」に移っており、運用の成熟度を測る指標が整い始めた。
Claude Help Center リリースノート·2026年9月·原文
このカテゴリの流れ：エージェントに何を渡すかの判断はチーム主導（HubSpot）で進む一方、Shopifyのように前提そのものを覆す設計判断も出てきた。Anthropic自身も使われ方の可視化にシフトしている。

🎯 今日の1個試すなら

Claude Coworkで、毎週やっている定型業務ひとつを「Routine」にスケジュール登録してみる。

①まずCoworkでいつも通りその作業を1回実行させ、出てくる成果物の形を確認する。②結果に納得できたら「これを毎週月曜9時に自動実行して」と指示してRoutine化する。③初回の自動実行後は必ず結果を確認し、期待とズレた出力があれば指示文を直して再登録する。着手する作業に迷ったら、公式ガイド（claude.com/blog/the-claude-cowork-product-guide）が挙げるリサーチブリーフ・会議準備・定例レポートのいずれかから始めるとよい。
収集条件／直近24〜72hを中心に、海外・日本のソースを半々。出力は日本語（英語ソースは翻訳・要約）。出典リンクを付けられない項目は載せていない。
